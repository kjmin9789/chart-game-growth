# 차트게임 시드 매출 성장 전략

## 목표와 선택 원칙

시드 매출을 최우선 성과로 삼는다. 실행 수단의 제약은 우선 열어두되, 기존 기능을 활용해 작게 바꾸고 매출 효과를 확인할 수 있는 실험을 우선한다. 이는 2026년 11월 24일 사용자가 정한 방향이다.

사용자는 차트게임 한 판 이용자의 리텐션이 높다고 관찰했다. 이는 탐색할 가치가 있다는 근거지만, 차트게임이 리텐션을 높인 인과 효과로 확정하지 않는다. 재방문 증대도 시드 구매로 이어지는 경로를 함께 설명해야 한다.

## 먼저 확인할 문제

| 문제 후보 | 확인할 질문 | 작게 검증할 방향 |
|---|---|---|
| 유료 가치가 전달되지 않음 | 반복 이용자가 시드를 사용하는 기능과 가치를 아는가? | 필요한 순간에 기존 유료 기능 하나의 가치 안내 |
| 구매 필요 시점에 경로가 끊김 | 시드가 필요한 상황에서 스토어·결제까지 갈 수 있는가? | 해당 상황의 구매 진입 동선 하나 개선 |
| 상품 또는 결제 과정에서 이탈 | 상품 확인 이후 어느 단계에서 멈추는가? | 확인된 장애물 하나 개선 |
| 첫 구매 후 재구매가 적음 | 구매한 시드가 어떤 가치에 쓰이고 후속 구매로 이어지는가? | 사용 맥락에 맞는 후속 안내 |
| 반복 이용 기회를 놓침 | 돌아올 의사가 있는 사람이 왜 이용을 멈추는가? | 기존 플레이·복기 맥락으로 복귀 유도 |

위 항목은 후보이며 현재 병목으로 확정하지 않았다. 외부 리텐션 사례의 상승률을 차트게임 예상 매출 상승률로 사용하지 않는다. 무료 시드 확대는 이용 증가와 유료 구매 감소를 함께 일으킬 수 있어 별도 검증한다.

## 진단 순서

첫 이용자, 반복 이용 비구매자, 기존 시드 구매자를 구분한다. 구독 여부도 함께 확인해 무료 혜택과 유료 시드 사용의 차이를 해석한다.

게임 진입 → 실제 플레이 → 시드 사용이 필요한 상황 → 스토어 진입 → 상품 선택 → 결제 완료 → 재구매 흐름을 확인한다. 각 단계의 이벤트 존재 여부와 정의부터 맞추고, 동일 집단·기간의 사용자 흐름을 확인한 경우에만 전환율을 계산한다.

별도 기능 조사 대화에서는 시작 클릭과 실제 시작, 결과 보기와 정상 완주, 일부 구매 이벤트와 실제 결제 완료가 다를 수 있다고 보고했다. 분석 전에 코드와 결제 집계를 대조한다. 단순 이벤트 사용자 수를 나눠 구매 퍼널로 해석하지 않는다.

## 임팩트와 측정

**주 지표 제안:** 고정된 관찰 기간의 실험 배정 사용자당 시드 순결제액. 시드 상품 결제액에서 취소·환불을 반영하고, 구독 결제와 구분한다. 정확한 매출 집계 기준과 환불 반영 시점은 분석 전에 확정한다.

**예상 추가 매출:** 같은 관찰 기간의 실험군과 대조군 간 사용자당 시드 순결제액 차이 × 동일 조건의 적용 가능 사용자 수. 실험 전 예상치에는 사용한 가정과 범위를 적는다. 기간이 다른 값을 곱하지 않는다.

보조 지표는 첫 구매율, 재구매율, 구매자당 결제액과 구매 단계별 전환이다. 보호 지표는 전체 구독 매출, 게임 재방문, 환불·불만 등이며 허용 악화 범위는 실행 전에 정한다. 클릭률과 시드 소모량만으로 매출 개선을 판정하지 않는다.

사용자 단위 무작위 배정이 가능하면 배정된 전체 사용자를 비교한다. 구매자·클릭자만 비교하지 않는다. 대상 규모, 현재 매출 분포, 검출할 최소 변화량을 바탕으로 실험 기간을 정한다. 소수 고액 결제자에 따른 변동도 확인한다. 배정이 불가능한 관찰 비교에서는 인과 효과 판단의 한계를 적는다.

## 첫 실험 선택

문제의 근거, 대상 규모, 매출에 이르는 경로, 작업량, 검증 가능성을 함께 비교해 상위 3개를 정리하고 하나를 고른다. 현재 데이터가 없는 항목에는 임의 점수를 넣지 않는다.

실험안에는 문제와 근거, 다른 원인 가능성, 대상·제외 조건, 변경 한 가지, 비교군, 주 지표·보호 지표, 기간·표본, 성공·중단 기준, 결과별 다음 행동을 기록한다. 표본이 부족하면 실패와 구분해 판단을 보류한다.
