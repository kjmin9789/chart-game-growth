# 차트게임 기획 결정 기록

## 2026년 11월 24일 기획 운영 범위

- **결정:** 개인 계정의 비공개 저장소에서 기획을 관리한다. 실제 코드 작업은 알파스퀘어 조직 저장소에서 진행한다.
- **이유:** 개인 기획 과정과 서비스 구현을 각각 관리하면서 요구사항·실험·PR을 연결하기 위해서다.
- **근거:** 현재 대화의 사용자 요청.

## 2026년 11월 24일 우선 사업 목표

- **결정:** 시드 매출을 최우선으로 삼고, 임팩트가 크면서 작업 규모가 작은 실험을 우선한다.
- **근거:** 「알파스퀘어 차트게임 기능 조사」 대화에서 사용자가 제시한 방향.
- **남은 결정:** 기준 매출, 구체적 목표 수치, 첫 실험, 담당자, 일정.
- **다시 검토할 조건:** 실제 결제 데이터와 대상 규모가 확보되거나 사업 목표가 바뀔 때.

## 후속 결정 기록 방법

결정일, 결정 내용, 이유와 근거, 검토한 대안, 다시 검토할 조건을 남긴다. 실험 결과에 따른 결정에는 해당 실험과 분석 결과를 연결한다.

## 2026년 11월 24일 조사에 따른 우선순위 제안

- **분석 제안:** 기존 구매자의 추가 구매 조건을 먼저 진단하고, 반복 이용 비구매자의 첫 구매도 병행 탐색한다. 실행 실험은 미확정이다.
- **근거:** [기준 현황](../research/2026-11-24-GA와-시드결제-기준현황.md)의 매출 집중과 기간별 결제 빈도 변화.
- **변경한 초기 후보:** GA 탐색 단계의 소액 상품 강조는 큰 구매를 대체할 수 있고 현재 관찰과의 연결이 약해 우선순위를 낮췄다.
- **남은 결정:** [P001의 세 후보](../problems/P001-기존구매자의-추가구매-조건.md) 중 무엇을 실행할지. 플레이·잔액·부족 상황과 실제 대상 규모를 확인한 뒤 정한다.
