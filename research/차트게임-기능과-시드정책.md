# 차트게임 기능과 시드 정책 조사

## 서비스 정의

차트게임은 실제 과거 차트를 활용해 매매 시점과 투자 비중을 반복 연습하고, 결과를 복기하며 다른 투자자와 경험을 나누는 투자 훈련 서비스다. 종목 정보가 공개되지 않은 차트에서 매수·매도·관망을 선택한다.

## 기능 조사 결과

| 영역 | 기존 조사에서 확인한 기능 | 실험 기획에서 확인할 지점 |
|---|---|---|
| 매매 연습 | 기본 50턴, 수량과 비중 선택, 현금·보유량·평단가 관리 | 첫 시작·실제 진행·정상 완주의 구분 |
| 차트 분석 | 지표·매매전략·드로잉, 시장·봉 주기 선택 | 기능 발견과 권한별 접근 차이 |
| 패턴 연습 | 패턴 선택. 확인한 생성 흐름은 국내주식 일봉에 적용 | 반복 연습 수요와 이용 권한 |
| 결과·복기 | 손익·거래비용·거래 횟수, 턴 이동 복기, 거래·게임 메모 | 결과 확인 후 다음 이용 경로 |
| 성장·경쟁 | 계좌 성과, 리그·순위·다이아 배지, 친구대전 | 경쟁이 실제 이용·구매로 연결되는지 |
| 공유·학습 | 게임 공유, 다른 사용자의 복기 구매, 복기 판매 시드 집계 | 유료 가치 경험과 시드 수요 |
| 입문 | 비로그인 게스트 게임과 튜토리얼 | 신규 이용자의 체험과 정착 |

핵심 타겟 가설은 차트 지식은 조금 있지만 진입·청산·비중 조절을 반복 연습하고 싶은 초급~중급 개인투자자다. 실제 사용자 조사로 확정한 세분화는 아니다.

## 시드 정책에서 일반화하면 안 되는 부분

턴 연장에는 권한에 따른 무료 연장과 시드 소모 연장이 함께 존재한다. 모든 사용자에게 같은 무료 횟수나 소모량을 가정하지 않는다. 상품 수량은 결제 집계에서 확인했지만, 운영 가격·무료 지급·사용처별 소모량·구독 권한은 실제 실험 대상 기준으로 다시 확인해야 한다.
