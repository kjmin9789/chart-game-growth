# P001 시드 재구매 유저 수 확대

시드 매출은 과거 월 200만 원까지 발생했지만, **2026년 10월 28일~11월 24일 집계액은 388,070원으로 약 80.6% 낮아졌다.** 최근 금액은 iOS 인앱결제의 0원 기록을 상품가격으로 보정한 값이며, 11월 24일 19:20까지의 기록을 포함한다. 과거 월 매출과 최근 28일간의 금액을 비교한 것으로, 매출 회복과 성장 가능성을 살펴보는 출발점이다.

## 1. 누구의 어떤 상황인가?

시드를 한 번 구매하고 차트게임을 이용한 사용자가, 구매한 시드를 활용한 뒤 다음 구매를 결정하는 상황이다.

## 2. 어떤 문제가 나타나고 있는가?

**한 번 구매한 사용자가 다시 구매하는 경험을 늘려야 한다.**

2026년 8월 26일~11월 23일 원화 시드 구매자 **81명 중 36명**이 기간 내 두 번 이상 구매했고, 나머지 **45명**은 한 번 구매했다. 반복 구매자는 전체 구매자의 **44.4%지만**, 전체 매출의 **78.6%를 만들었다**.

기간 내 한 번 구매한 45명이 모두 실제 첫 구매자이거나 재구매에 실패한 사용자는 아니다. 분석 기간 이전 구매 이력과 실제 첫 구매 이후의 관찰 기간을 확인해야 한다.

## 3. 어떤 영향을 주는가?

90일 원화 결제액 **2,796,020원 중 2,196,780원**이 반복 구매자에게서 발생했다. 반복 구매자 기반이 커지면 일회성 구매에 그치지 않고 지속적으로 발생하는 매출을 늘릴 수 있다.

## 4. 왜 지금 풀 가치가 있는가?

시드를 다시 구매하는 사용자가 매출의 대부분을 만들고 있다. 이미 한 번 지불 의사를 보여준 사용자가 구매한 가치를 경험하고 다시 구매하도록 돕는 것은 매출 회복을 위해 살펴볼 가치가 큰 구간이다.

현재 반복 구매자의 구매량을 늘리는 것과 함께, **반복 구매자가 되는 사람 자체를 늘리는 방향**으로 성장 기반을 넓힐 필요가 있다.

## 5. 그래서 어떤 문제를 정의하는가?

> **시드를 처음 구매한 사용자가 구매한 가치를 경험하고 다음 구매로 이어지도록 개선해, 재구매 유저 수를 늘린다.**

분석의 중심은 **첫 구매 → 구매한 시드 활용 → 지속 이용 → 두 번째 구매**다. 기간 내 구매 횟수로 본 현황을 출발점으로 삼고, 첫 구매 이후의 흐름은 실제 첫 구매일을 기준으로 살펴본다.

## 원인 가설과 실험 초안

대상은 실제 구매 이력이 한 번이고 아직 두 번째 구매가 없는 사용자다. 실제 첫 구매일을 기준으로 같은 기간을 관찰하고, 잔액이 충분해 계속 이용하는 사람과 이용을 멈춘 사람, 시드 부족 이후 구매하지 않은 사람을 구분한다.

| 후보 | 원인 가설 | 실험 내용 |
|---|---|---|
| **1안. 기존 충전 안내의 시각 효과와 카피 강화** | 시드 부족 시 충전 안내는 이미 있지만, 눈에 띄지 않고 계속 도전할 이유를 자극하지 못해 두 번째 구매로 이어지지 않는다. | 기존 충전 안내의 색상 대비·상품 카드 크기·시드 애니메이션을 강화한다. 게임 시작에는 ‘이번 차트, 어디까지 읽을 수 있습니까?’, 턴 연장에는 ‘다음 턴을 앞두고 멈추겠습니까?’처럼 도전을 자극하는 카피를 제안하고 ‘시드 충전’ 버튼을 강조한다. 필요 시드·부족분·상품 수량·가격과 기존 선택·복귀 흐름은 유지한다. |
| **2안. 복기 미사용자에게 추가 시드 사용처 안내** | 시드를 게임 시작·턴 연장에만 쓰는 것으로 알고, 복기에도 사용할 수 있다는 사실을 몰라 추가 시드 수요가 생기지 않는다. | 복기 미사용자의 결과 화면에 ‘매매가 끝나도 연습은 끝나지 않습니다. 시드로 복기하며 놓친 흐름을 확인할 수 있습니다’ 툴팁을 보여준다. 복기 진입 시 실제 필요한 시드를 안내하고, 사용자가 비용을 확인한 뒤 이용하게 한다. |
| **3안. 첫 구매 활용 미션** | 자유롭게 플레이하는 것만으로는 구매한 시드를 어떻게 활용할지 알기 어렵다. | ‘게임 한 판 완료 → 거래 한 번 복기 → 비슷한 패턴 재연습’ 미션과 진행 상황을 보여주고, 완료하면 3시드를 지급한다. 제공 가능한 패턴과 권한별 비용, 미션 완료 조건은 실행 전에 확인·정의한다. 3시드는 이 실험의 제안 수치다. |

### 추가 후보

| 후보 | 원인 가설 | 실험 내용 |
|---|---|---|
| **4안. 충전 중단자에게 하려던 행동 다시 안내** | 충전을 열었다가 구매를 미룬 뒤 돌아올 계기가 없다. | 시드 부족으로 충전을 열었지만 구매하지 않은 사람에게 중단한 게임과 이어서 할 행동을 앱 내에서 다시 보여준다. 이미 구매하거나 해당 행동을 마친 사람은 제외한다. |
| **5안. 두 번째 구매에 추가 시드 지급** | 계속 이용할 생각은 있지만 추가 지출을 결정할 만큼 상품의 매력이 충분하지 않다. | 두 번째 구매에 한해 3시드 추가 지급을 제안한다. 두 번째 구매에 한 번만 적용하며, 3시드는 이 실험의 제안 수치다. |

각 안은 해당 변경을 적용하지 않은 대조군과 비교한다. 같은 관찰 기간에 두 번째 구매를 한 사람의 수와 비율을 주로 확인하고, 복기·미션 완료·재방문·플레이는 중간 행동으로 확인한다. 보상안은 지급 시드량·결제액·이후 구매도 함께 확인한다.
